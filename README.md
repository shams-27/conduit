# Conduit

![Conduit](conduit.png)

**A single, distraction-free start page for the DIU student workflow.**

Live: [shams-27.github.io/conduit](https://shams-27.github.io/conduit/)

---

## The Problem

A typical study session starts with a scramble across a dozen browser tabs — the Student Portal for a routine, BLC for a lecture, a notice board for an announcement, plus whatever AI tools, docs, and reference sites are needed to actually get work done. Each of these lives on a different site, bookmarked (or not) in a different place, surfaced through a browser new-tab page that's built for general browsing, not for a student's actual routine.

Conduit replaces that scramble with one page. It brings the essential DIU services, a curated set of study and productivity tools, and a personal bookmark system into a single organized dashboard — so opening a new tab means opening your workspace, not hunting for it.

---

## Features

### DIU Hub
One dropdown with direct links to the tools a DIU student reaches for constantly: Student Portal, Live Result, BLC, Campus Schedule, DIU Routine, Notice Board, DIU QBank, Payment Ledger, Teaching Evaluation, and Semester Result — no more digging through bookmarks or retyping URLs.

### Curated Resource Grid
Dozens of external tools organized into focused categories, so the right tool is always one click away:
- **AI** — Claude, ChatGPT, Gemini, Perplexity, Grok, DeepSeek, NotebookLM
- **Learn** — YouTube, GeeksforGeeks, W3Schools, VisuAlgo, freeCodeCamp, Codecademy
- **DSA** — LeetCode, Codeforces, HackerRank, CodeChef, SPOJ, HackerEarth, InterviewBit
- **Google Tools & Storage** — Docs, Sheets, Slides, Drive, Dropbox, OneDrive
- **Design, PDF, Diagramming, Citations, Dev Tools, Grammar, Passwords, Career**, and more

### Quick Bookmark Tray
A persistent bookmark bar in the header for the links a student uses most. Add a custom link through a simple modal — name and URL — and it's saved and ready every time the page loads.

### Built-In Calendar
A dropdown calendar right in the header, so checking a date or planning around a deadline doesn't require leaving the page or opening a separate app.

### Clean, Focused Interface
No ads, no news feeds, no algorithmic noise — just the tools a student actually needs, laid out clearly and ready to use.
